## Source classes
- ORIGINAL_SOURCE — author manuscript, direct author text, supplied artifact.
- AUTHOR_DECISION — explicit author correction/decision.
- VERIFIED_RESEARCH — externally verified evidence.
- DERIVED_CANON — conclusion derived from sources and explicitly recorded.
- WORKING_PLAN — implementation plan; not canon.
- RECONSTRUCTION — rebuilt from incomplete evidence; never source authority.
- QUARANTINED — preserved history that must not drive new work.

## Registration requirement
For every recovered source record:
- source ID;
- original path/name;
- archive path;
- source type;
- date/time if known;
- exact provenance;
- what it establishes;
- what it does not establish;
- dependent chapters/documents;
- superseded claims;
- confidence;
- verification status.

## Recovery rule
A document is not promoted merely because it sounds plausible, appears newer, or matches model memory. Promotion requires evidence.
