# Decision Log

Record important project decisions here, including the reasoning and date when known.

## Confirmed Decisions

### Documentation Home
**Decision:** GitHub is the authoritative home for EverWorlds project documentation.

**Reason:** The project is software-oriented, benefits from version history, and its documentation needs to remain closely connected to implementation and technical development.

### Separation of Documentation and Implementation
**Decision:** Project concepts, requirements, decisions, terminology, and production planning are documented explicitly rather than being left solely inside application code or tooling.

**Reason:** This keeps project knowledge discoverable and prevents ideas from becoming buried in implementation details.

### Scheme of Work Purpose
**Decision:** The Scheme of Work is a project productivity/production framework rather than a school-style scheme of work.

**Reason:** Its purpose is to support completion of the project while reducing burnout, disorder, messes, and inconsistencies.
