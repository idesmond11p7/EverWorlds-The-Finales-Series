## How to migrate

1. Open the new fanfiction repository once it has been created.
2. Copy the **contents of this folder** into the root of that new repository, preserving directory paths. Do not copy the outer `MIGRATION_BUNDLE_APOCRYPHA_DXD_FOREVER/` directory itself unless you specifically want an extra nesting level.
3. Keep `00_MIGRATION_README.md` and `00_SOURCE_MANIFEST.md` as migration records, or move them into a `_MIGRATION/` folder after review.
4. Verify the copied file count and compare the important source files before treating the migration as complete.
5. Update the new repository's root README to designate it as the **active primary workspace** for the fanfiction and its worldbuilding.
6. Retain the old repository as a **legacy/reference repository** containing historical work, obsolete concepts, prior drafts, and provenance. Do not delete its contents.
