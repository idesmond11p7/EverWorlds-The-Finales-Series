# Scheme of Work — Apocrypha Recovery and Production

STATUS: ACTIVE — MASTER PLAN
LAST VERIFIED: 2026-10-06

## Mission
Recover the project's actual knowledge, establish provenance, rebuild documentation that constrains model limitations, then resume narrative production without contaminating canon.

## Phase 0 — Preserve
DONE: move all existing Markdown documentation into _ARCHIVE_PRE_RESET_2026-10-06/ without losing Git history.

## Phase 1 — Recover
- audit every archived document;
- identify original manuscripts versus reconstructions;
- extract exact dates, times, quotes, decisions, and chronology;
- compare Git history where ambiguity exists;
- classify information.

Completion condition: every information-bearing archive file has a source classification and routing record.

## Phase 2 — Reconstruct canon
- establish chapter-by-chapter source truth;
- rebuild character knowledge boundaries;
- rebuild world/mechanics canon;
- record contradictions and corrections;
- establish what remains UNKNOWN.

Completion condition: no active canon claim lacks provenance.

## Phase 3 — Rebuild production architecture
Create chapter plans only from recovered canon. Build dependency maps, research requirements, and scene-level control documents.

Completion condition: Chapter 8 and Chapter 13 have verified upstream states.

## Phase 4 — Resume production
Only after Phase 3 passes: develop Chapter 8 and Chapter 13 according to their verified dependencies.

## Phase 5 — Release control
Every chapter passes source check → continuity check → prose audit → author review → explicit release record.

## Never skip
Recovery cannot be skipped because a chapter “feels remembered.” A known blocker cannot be bypassed by “next.”
