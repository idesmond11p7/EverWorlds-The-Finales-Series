# Terminology Register

Controlled vocabulary for the project. Definitions here should be used consistently across documentation.

| Term | Definition |
|---|---|
| **EverWorlds Series: The Finales** | The overall project producing the EverWorlds extension and its associated Finale outputs. |
| **EverWorlds** | The large-scale React-based extension for SillyTavern that heavily modifies SillyTavern's properties and behavior while adding capabilities and a specific roleplay structure. |
| **Finale** | A deeply evolved version of an existing world that preserves its identity and defining traits while becoming unrecognizably better. |
| **Digital Twin** | A highly detailed representation of a world, person, or other subject intended to reproduce relevant characteristics with strong psychological realism. |
| **Scheme of Work** | The project's productivity and production framework used to organize work toward the end goal. |

## Terminology Rule

If a term acquires a more precise project-specific meaning, update this register before allowing competing definitions to spread through project documentation.
